# Installation

1. Extract the collection on your computer.
2. Copy its PTF files to PSP/THEME on the PSP Memory Stick.
3. Open XMB Settings → Theme Settings → Theme, select one and choose Apply.
4. A replacement prompt concerns the stored active theme; other files remain on the card.
5. If an earlier wallpaper remains, select Background → Custom Theme.

Check folder nesting and completed transfer if a theme is missing. Apply through the standard XMB. See [compatibility](COMPATIBILITY.md) for active CTF/CXMB configurations.
