# KP PSP PTF Collection 1.0

Nine native themes, combining four restored releases with five new designs:

- Aero Vista — Aurora
- Candy Glass
- Eesti Retro — 80–90ndad
- KP Aero — Vibrant Blue
- Windows XP — Autumn
- Winter Moscow
- Ocean — Frutiger Aqua
- Mac OS 9 — Platinum
- Mac OS X 10 — Aqua

Original PTF bytes and theme version 1.0 are preserved; total PTF size is 3.80 MiB.

Includes previews, wallpaper PNGs, a gallery, bilingual instructions, source assets, component notices, hashes and recorded desktop checks.

All nine files and 661 graphics passed desktop verification. Rebuilding reproduced every original file byte for byte in the recorded environment. Physical PSP testing remains pending.
