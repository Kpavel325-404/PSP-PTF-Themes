# Установка

1. Распакуй коллекцию на компьютере.
2. Перенеси её PTF в PSP/THEME на карте PSP.
3. Открой XMB: Настройки → Настройки темы → Тема, выбери нужную и нажми «Применить».
4. Запрос перезаписи касается активной темы; остальные файлы остаются на карте.
5. Если остались прежние обои: Фон → Специальная тема.

Если тема отсутствует, проверь вложенность папок и завершение копирования. Применяй через штатный XMB. Для активных CTF/CXMB-конфигураций смотри [совместимость](COMPATIBILITY.md).
